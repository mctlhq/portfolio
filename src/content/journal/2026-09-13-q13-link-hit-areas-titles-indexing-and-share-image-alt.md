  en: "Four mechanical defects an external UX audit measured on production 0.1.23 and on main: .project-links a, .breadcrumb a, .journal-meta a and .table-scroll a carried no hit-area rule at all and measured 17-20px against the 24px floor test/a11y.test.ts already enforces for six other selectors, so they now carry the same min-block-size: 24px / inline-flex shape and the test's TARGET_SELECTORS covers all ten; journal and ADR titles had no length budget and 24 of them rendered over 65 characters (one at exactly 127), so src/lib/seo.ts now exports titleProblems, journalPageTitle and adrPageTitle, both routes render through them, 24 entries carry an explicit seoTitle, and test/title.test.ts computes every route's rendered title from the content files instead of a hand-typed list; every one of the 24 public journal entries reached the sitemap regardless of whether it answered a real search question or was an internal build note, so the journal schema gained an indexing: index | noindex field, astro.config.mjs's sitemap filter and scripts/check-dist.mjs's expected-set derivation both read it from src/lib/indexing.ts, and a noindex page still renders its canonical alongside noindex,follow rather than losing it; and Base.astro's og:image/twitter:image carried no alt text and no page carried structured data, so both now carry a fixed English alt string and journal/ADR pages carry one BreadcrumbList JSON-LD block built from the same values the visible breadcrumb renders, with src/lib/csp.ts's inline-script regex narrowed so the ld+json data block is never mistaken for a second inline script. The 404 page also gained a link to /work/ and a mailto: contact link below the existing home link."
